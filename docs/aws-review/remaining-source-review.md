## Clearly surfaced gaps and limits

- Remaining metadata-detector gaps and pending candidates are identified individually below. Safe transient inspection can discard values before caching; sensitive input alone is not a reason to call the check unnecessary.
- Batch environment coverage excludes commands/unsupported variants; Amplify app environment excludes buildSpec/customHeaders/backend fields; Glue visible properties exclude hidden password fields. These are explicit residuals, not full scanner replacements.
- Route53 account ownership is insufficient: a legitimate other-account AWS IP or existing S3 website can be an intended DNS target. Unmatched-target inventory may be useful, but absence from this account is not proof of takeover.
- Sampled S3 examines first <=20 current-object ACLs per account-global bucket, once across Regions. Public positive evidence survives partial sampling; incomplete private samples stay UNKNOWN. BOE/IgnorePublicAcls suppression is explicit; policy access, unseen objects, versions and intended websites are unassessed.
- Inspector Classic is retired (2026-05-20); the active Inspector2 successor has different statuses, resource model, severity threshold and scope.
