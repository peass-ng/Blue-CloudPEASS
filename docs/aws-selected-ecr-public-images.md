# Selected ECR Public image content

Set `selected_aws_ecr_public_images` to one or two exact `{scope, registry_alias, repository_name, image_digest}` objects. `scope` must be an explicitly selected `ACCOUNT/us-east-1` scope, and `image_digest` must be a lowercase `sha256:` digest of a single OCI or Docker manifest. The selected account must own an `ACTIVE` alias returned by ECR Public; a lookalike alias supplied only in options is insufficient. Mutable tags, manifest lists, and image indexes are unsupported.

Select `aws.review.ecr_public.selected_image_secret_indicators` with `content_secret_scans=true` for Kingfisher and TruffleHog, or `aws.review.ecr_public.selected_image_high_vulnerabilities` with `image_vulnerability_scans=true` for optional Trivy HIGH/CRITICAL findings. Both are disabled by default. The existing AWS connector principal needs `ecr-public:DescribeRegistries`, `ecr-public:DescribeRepositories`, and `ecr-public:DescribeImages` in us-east-1 in addition to its existing `sts:GetCallerIdentity` scope proof. The ECR Public API reads and anonymous `https://public.ecr.aws` OCI GETs are the only network operations in this path; AWS credentials are never sent to the registry host.

The producer reads the registry, exact repository, and exact image digest before and after downloading one leaf manifest, config, and all layers. It verifies every SHA-256 digest, descriptor size, rootfs diff ID, and supported TAR structure before a clean result. Private temporary layer files are removed after inspection. Unsupported archive/binary content, a denied or truncated read, alias drift, digest drift, incomplete detectors, or a stale/unavailable Trivy database yields UNKNOWN for a clean result; a confirmed secret or HIGH/CRITICAL finding remains FAIL.

Official AWS contracts: [DescribeRegistries](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_DescribeRegistries.html), [RegistryAlias](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_RegistryAlias.html), [DescribeRepositories](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_DescribeRepositories.html), [DescribeImages](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_DescribeImages.html), and [public registry image URI](https://docs.aws.amazon.com/AmazonECR/latest/public/public-registries.html).
