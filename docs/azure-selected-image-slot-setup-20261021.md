# Azure selected image and slot read setup

The ACR image secret path requires `content_secret_scans: true`, its named check, and exact `selected_azure_acr_images` with an immutable manifest digest. The separate ACR high and critical vulnerability path requires `image_vulnerability_scans: true`, its own named check, and exact `selected_azure_acr_image_vulnerabilities`; the secret flag grants no vulnerability scan. Both stay default off and require explicit subscription scope and exact registry and repository selection.

For either ACR path, grant `Microsoft.ContainerRegistry/registries/read` to read the selected registry's native ARM metadata. Legacy registry permissions additionally need `AcrPull`, whose action is `Microsoft.ContainerRegistry/registries/pull/read`. In an ABAC registry, `Container Registry Repository Reader` grants the repository data actions `Microsoft.ContainerRegistry/registries/repositories/metadata/read` and `Microsoft.ContainerRegistry/registries/repositories/content/read`; grant at the selected repository scope or with its matching condition. Content read is required for the exact manifest, config, and layers, while metadata read supports repository identity. [Microsoft's built-in role definitions](https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles/containers) list these actions. ARM subscription Reader by itself does not grant repository pull.

The selected App Service or Function slot package path additionally reads the exact slot metadata with `Microsoft.Web/sites/slots/read` and its own sensitive app settings with `Microsoft.Web/sites/slots/config/list/action`. It also reads subscription metadata with `Microsoft.Resources/subscriptions/read`, storage account metadata with `Microsoft.Storage/storageAccounts/read`, and the exact selected ZIP Blob with `Microsoft.Storage/storageAccounts/blobServices/containers/blobs/read` DataAction, for example through Storage Blob Data Reader. The slot settings API is [`POST .../sites/{site}/slots/{slot}/config/appsettings/list`](https://learn.microsoft.com/en-us/rest/api/appservice/web-apps/list-application-settings-slot?view=rest-appservice-2025-03-01), a read operation; the selected slot metadata API is [`GET .../sites/{site}/slots/{slot}`](https://learn.microsoft.com/en-us/rest/api/appservice/web-apps/get-slot?view=rest-appservice-2025-03-01). The caller needs ARM and Storage OAuth access and Blob download authorization. ARM Reader or a parent production site's app settings are insufficient.

The portable tests use offline native DTOs and fake HTTPS. They do not establish live tenant grants, pull access, deployment use, or production admission. Slot support remains blocked until the reviewed source transaction is admitted.
