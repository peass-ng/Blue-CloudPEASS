## Residual doubts

- Application password hashing, physical premises, personnel actions and legal privacy consent cannot be inferred from AWS control-plane configuration; their rows call for named organizational or application evidence.

- Existing Config recorder evaluator can pass when no recorder exists; rows using it remain PARTIAL pending the stricter proposed completeness evaluator.
