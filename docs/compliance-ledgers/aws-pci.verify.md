## Validation and limits

- Validation script: `docs/compliance-ledgers/.work/aws-pci/validate.py`. It compares every requirement ID and count with frozen input, checks every native ID against the catalogue, enforces decision shape and specification consistency, and checks checklist alignment.
- Catalogue `source` points to registry locations in `peaso/checks/__init__.py` for most checks, and these lines do not contain literal IDs in the current checkout. The validator therefore treats the catalogue as the ID authority and reports locations without literal IDs separately.
- Parameterized new checks require caller-supplied approved inventories, thresholds or expected values before implementation. No AWS APIs were called.
