# Composer DAG source secret inspection

Candidate `gcp.review.composer.dag_source_secret_indicators` implements a high-severity desired-state secrets check over native inventory `composer_dag_source`. **75 focused tests pass**, including actual pinned Kingfisher 1.4.0 and TruffleHog 3.92.5. Root applied the collector/engine hooks during this dispatch; check installation and canonical admission remain root-owned.

[Composer documents `config.dagGcsPrefix`](https://docs.cloud.google.com/composer/docs/reference/rest/v1/projects.locations.environments#EnvironmentConfig) as the output-only prefix for an environment’s DAG objects. The adapter accepts it only from a complete native Composer inventory with actual source receipts. Independent CRM v3 identity and bucket `projectNumber` bind ownership to the requested project; project ID/number aliases require that independent proof. Missing/masked fields, cross-project buckets and external URLs cannot select content.

A boolean `content_secret_scans` and the exact named check’s trusted planner kind are required. Default, bulk-only, metadata-only or unselected adapter calls perform zero additional list/media/scanner calls. The new reader uses uncached, bounded [Storage prefix listing](https://docs.cloud.google.com/storage/docs/json_api/v1/objects/list) with minimal fields and complete pagination. It passes each exact listed generation to the existing audited [object metadata/media reader](https://docs.cloud.google.com/storage/docs/json_api/v1/objects/get), including generation preconditions and media identity/type/size checks. It executes no DAGs and never reads managed secrets.

Limits are three environments per scope, six files and three listing pages per environment, and 16 KiB per listing response. Media shares the selected-object reader’s one-MiB object limit, eight-MiB total limit, twenty-call limit, thirty-second deadline and serialized state across scopes/services. Native transport limits, cancellation and tightened raw-socket deadlines also apply. Streams close on all tested success/failure branches; redirects and provider error bodies are refused. Unsafe HTTP debug logging disables source reads.

Supported regular UTF8 DAG/config extensions are `.py`, `.json`, `.yaml`, `.yml`, `.toml`, `.ini`, `.cfg`, `.txt`, `.sql` and `.sqlx`, with supported text media types. An empty prefix, unsupported object, binary/archive, encryption, missing generation, denied/truncated response, incomplete listing, tool failure or exhausted bound yields UNKNOWN. A clean verdict requires both detectors to finish every listed file. It covers only observed generations under this prefix: concurrent changes, plugins, data/log folders and other environment surfaces are outside that claim.

Source text, filenames, cursors, auth and provider snippets never enter snapshots, evidence, the generic JSON cache or fixtures. Results retain the environment owner, opaque selector identities, bounded counts and redacted keyed leak observations. Distinct opaque file positions remain visible while the shared merger produces one hidden finding per exact value across tools/files/owners. Concurrent provenance attribution filters exact scope and owner/list or attempted immutable-file identity; the consumer rejects foreign or unexplained receipts.
