## Delivered behavior

Public exports are `evaluate_reachability`, `network_snapshot`, and
`REACHABILITY_TYPES`. The evaluator accepts one snapshot, global inventory source
and destination IDs, TCP/UDP, destination port, optional source port, and IPv4/IPv6.
It returns `allowed`, `blocked`, or `unknown`, with route/policy decisions,
translations, unresolved dependencies, native evidence paths, context evidence,
and original/scoped snapshot IDs. Configuration allowance never establishes
application listening, packet delivery, or endpoint operating state.

- AWS: attached SG egress/ingress allow unions; SG-owner-aware references;
  stateful replies; explicit/main-table routing and active owner/region-qualified
  peering; ordered stateless NACLs in both directions including return ports;
  same-subnet NACL exemption and active address-family facts.
- Azure: NIC/subnet NSG intersection, native priority/default semantics, stateful
  replies, source-port and service-tag uncertainty, local/peered system routes
  plus UDR precedence/drop, and peering synchronization checks.
- GCP: global/shared host-project identity and completeness, numeric ID versus
  project-qualified `selfLink`, tags/service accounts/ranges, ordered allow/deny
  with deny ties, stateful replies, and supported regular-subnet/active-peering
  routing under verified higher-policy/routing context.
- Kubernetes: independent ingress/egress additive unions, conjunctive selectors
  within a peer, named/numeric ports and evidenced ranges/IP-block exceptions,
  explicit cluster identity, and enforcing CNI/routing evidence. Namespace is
  administrative scope and is not converted to a subnet.

Missing or incomplete coverage remains unknown. An applicable source egress/drop
can block despite allowance gaps; an unproven downstream CIDR denial cannot become
a whole-flow proof when an unsupported transformation could change the address.
The evaluator performs no cloud SDK calls, sockets, subprocesses, network probes,
privileged writes, all-pairs computation, or exploitation.

The network artifact retains complete native dependency collections and their
