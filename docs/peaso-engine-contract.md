# Engine integration contract, schema 1.0

Core owns snapshot.py, engine.py, reports.py, CLI, collectors/base.py and collectors/__init__.py. Provider workers own collectors/{aws,gcp,azure,k8s}.py; rule worker owns checks/**; defensive analysis worker owns analysis/**. Existing initial native checks are transferred to checks/__init__.py for expansion. Do not change the schema without mail to core.

## Provider collector

`collect(connector:dict, requirements:list[str]|None=None)->dict` returns a sealed snapshot via `peaso.snapshot.make_snapshot(provider, scopes, collections, metadata=...)`. `requirements` is resource types, not check IDs; None requests all supported inventory. Connector has provider,name,auth,scopes,options. Never return auth, tokens, secrets, raw exception bodies. Scopes retain user selection; AWS account scopes with options.regions (legacy region scopes normalize to authoritative account/region), GCP project/org/folder scopes, Azure subscription/management-group/tenant scopes (empty/* discovery), K8s namespace scopes qualified by cluster context.

Snapshot `{schema_version:"1.0", snapshot_id:"sha256:...", provider, scopes:list[str], created_at:ISO, collections:list, metadata:dict}`. Each collection `{type:str, scope:str, service:str, status:str, items:list[dict], error?:{kind,code}}`. Types: AWS iam_user,iam_group,iam_role,iam_policy,bucket,vpc,subnet,security_group,instance,route_table; GCP iam_policy,bucket,network,subnetwork,firewall,instance; Azure role_assignment,role_definition,storage_account,vnet,nsg,nic,vm; K8s role,clusterrole,rolebinding,clusterrolebinding,serviceaccount,pod,service,networkpolicy,namespace. Expand via shared TYPES/notify core and rules worker. Native payload fields retained without renaming (Arn, properties, metadata, etc). Embedded failed details `{collection_status:"denied"|"unknown"|"timeout", error:{code}}`.

Collection statuses collected,empty,partial,denied,unknown,malformed,timeout,not_collected; unavailable and empty must have items=[]; partial may have evidence from successful pages. Collections unique by (type,scope), resources dedup by native ID within them. Scope global/account inventories once under first selected scope; metadata may record account ID/native scope. Collector/base.py exports Collector(provider,scopes,options), Budget.call for calls, collect(kind,scope,service,fetch_iterator_of_list_pages), finish(); _http_pages, _aws_pages generic helpers. Bounds options max_pages (1..100 default10), max_resources (1..100000 default10000, total), max_calls (1..10000 default200). Return partial on caps, never complete. Enforce safe pagination origins, GET/list except explicitly read-only getIamPolicy RPC. AWS never create/delete Access Analyzer.

## Native rules

`peaso.checks.CHECKS` list immutable Check objects: id,provider,category,kind,title,severity,control,remediation,evaluate(item_native_dict,index)->(status,evidence_dict). `Check.public()` returns catalog object id,provider,category,type,title,severity,frameworks:list[str],mapping:dict,remediation. Existing `register` decorator available; evaluator catches malformed/missing exceptions and returns UNKNOWN. Index includes kind->[resource], collections:{kind:[collection]}, restricted to authoritative scope for native rules; resources `{id:global_digest,native_id,type,scope,provider,service,data:native_dict}`. Evaluation is offline, pure, no cloud calls. Check statuses PASS,FAIL,UNKNOWN,DENIED,EMPTY,MANUAL,NOT_APPLICABLE; severity critical/high/medium/low/info. Every check maps HackTricks Cloud Best Practices; additional framework tags require reviewed pinned source/control provenance and never imply certification. Categories hardening,exposure,least_privilege,iam_graph,network.

## Defensive graph

`peaso.analysis.build_graphs(snapshot,resources,index=None)->{network:{nodes,edges},iam:{nodes,edges}}`. Node `{id:str,label:str,type:str,provider,scope,resource_id?,evidence?:dict}`. Edge `{id:str,source:str,target:str,type:str,evidence:dict,confidence:"high"|"medium"|"low"}`. Native references establish inventory relationships; IAM edges declared grants/trust/bindings only. No reachability/effective-access claims without evidence, no action chains or technique catalog. All graph IDs globally unique and deterministic, preserve scope/type in node IDs.

## Public engine and API

`collect_snapshot(request:dict)->dict` accepts full `{connector:... ,categories,checks,frameworks}`; also accepts connector directly for compatibility. `evaluate_snapshot(snapshot,categories=None,checks=None,frameworks=None)->dict` returns required report fields. `run_scan(request)->dict` adds snapshot to report. `catalog()->{providers:[str],categories:[str],checks:[Check.public],frameworks:[{id,name}]}`. Report required schema_version,snapshot_id,provider,scopes,created_at,resources,findings,coverage,graphs,stats. Finding id,category,check_id,title,provider,service,resource_id,scope,severity,status (uppercase),frameworks:list[str],evidence:dict,remediation. Coverage uses level:collection|check, type/check_id,scope,status,reason and includes missing inventory explicitly. Framework IDs accepted hacktricks,nist_800_53 as aliases to display names.

Empty category/check/framework lists mean default all for API compatibility. Core plan_collection(request) unions native check dependencies with selected analysis/graph requirements before live reads, explicit options.inventories overrides that plan to exactly requested types, and options.collect_all=true requests complete supported inventory; omitted prerequisites remain unknown coverage. Source snapshot digest changes are ignored when diffing stable finding evidence, while native configuration/evidence changes remain visible.
