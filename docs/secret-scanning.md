# Runtime environment/configuration secret coverage (2026-10-22)

Scope: exact installed check/engine mappings and collector routing in this checkout. Module docstrings were not taken as proof. `content_secret_scans=true` plus an explicitly named check is required for every offline literal scan below; category/framework/all-check selection may show an UNKNOWN check, but does not authorize content collection. The pinned Kingfisher 1.4.0 and TruffleHog 3.92.5 adapters scan offline without credential verification. For the automatic workload paths below, omitting the explicit target option discovers targets from the native inventory. It does not authorize arbitrary secret-store reads.

`engine.py` maps named IDs to `_content_secret_scan_kinds`; the collectors require that internal grant as well as the boolean. The check catalog installs the cited predicates. There are automatic metadata/name heuristics outside this table; they do not constitute literal TH/KF scanning and do not establish absence of secrets. Dynamic runtime overrides, secret stores, masked native values, arbitrary Kubernetes custom resources and unsupported native identity mappings remain outside automatic literal scanning.


Automatic workload discovery processes every valid discovered target in deterministic bounded batches, with separate native capture and receipt metadata for each batch. It does not stop at the first eight or sixteen targets. Batches run sequentially on each scan-local reader to preserve its request and redaction state. Coverage records each target as inspected, denied, scanner incomplete, failed or uninspected. Permission denials remain denied; detector failures remain incomplete. Incomplete inventory cannot establish complete clean coverage.

Enable content scanning and select the matching named checks before launching. Supply explicit targets for paths without automatic native identity mapping. A completed scan covers its requested selections; it does not imply that every optional source was inspected. Denied, truncated or unsupported reads cannot establish absence of secrets.
