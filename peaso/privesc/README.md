# peaso.privesc

Privilege-escalation technique catalog (YAML, `catalog/<provider>/*.yaml`) and the
read-only evaluator that turns catalog × snapshot into principal → principal edges for
the Privilege Escalation Map. Schema: `docs/peaso-privesc-schema.md`.

Validation commands, provider test coverage, scoped credential requirements and
live-test cleanup: [Privilege-escalation validation](../../docs/peaso-privesc-testing.md).
